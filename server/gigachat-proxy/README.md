# Прокси GigaChat для кнопки «✨ ИИ»

Сайт публичный, поэтому ключ GigaChat нельзя класть в его код — его увидел бы любой. Ключ хранится только здесь, в настройках облачной функции. Сайт отправляет вопрос с кусками конспектов на эту функцию, а она — в GigaChat.

## Как запустить (Yandex Cloud Functions, бесплатного лимита хватает)

1. Зайди в console.yandex.cloud → **Cloud Functions** → **Создать функцию** (имя, например, `mitya-ai`).
2. Среда выполнения — **Node.js 22** (или 18/20). Способ — «Редактор кода», файл `index.js`: вставь содержимое `index.js` из этой папки.
3. Точка входа: `index.handler`. Таймаут: **60 с**. Память: 128 МБ.
4. **Переменные окружения**:
   - `GIGACHAT_KEY` — «Ключ авторизации» из developers.sber.ru (длинная строка в base64);
   - при желании `GIGACHAT_MODEL` = `GigaChat-Pro` или `GigaChat-Max`.
5. Сохрани версию и включи **«Публичная функция»**. Скопируй адрес вида `https://functions.yandexcloud.net/d4e…`.
6. На сайте: ✨ → ⚙ → вставь этот адрес → «Сохранить». Или пришли адрес мне — я пропишу его в `lib/ai-config.js`, и ИИ заработает на всех устройствах сразу.

Проверка: открой адрес функции в браузере — должно показать `{"ok":true,…,"key":true}`.

## Если ошибка про сертификат

Серверы GigaChat подписаны сертификатом Минцифры. Если функция ему не доверяет, скачай «Russian Trusted Root CA» с gu-st.ru (формат PEM) и вставь его текст целиком в переменную `GIGACHAT_CA`. Крайний вариант — `GIGACHAT_SKIP_TLS=1` (проверка сертификата отключается, это менее безопасно).

## Что умеет ИИ на сайте

- Знает карту сайта: все предметы и лекции с датами, страницу, которая сейчас открыта, и как пользоваться сайтом.
- Перед ответом сам находит подходящие куски конспектов, карточек и тестов и опирается на них — с метками [С1], [С2], по ним можно перейти к разделу.
- Если на сайте ответа нет или нажата 🌐 — ищет статьи в Википедии и ссылается на них [В1].
- Может ссылаться на лекции кнопками перехода, объяснять проще и гонять по вопросам с разбором ответов.

Разрешённый сайт задаётся `ALLOWED_ORIGINS` (по умолчанию `https://mitriisi.github.io`).
